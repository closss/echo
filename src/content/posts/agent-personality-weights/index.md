## 一群说话一样的人

如果你跑过 Generative Agents 那一类多智能体小镇，大概见过这样的场面：每个 agent 都有名字、职业和一段写得很用心的身世，可放在一起聊上一阵，它们就开始像同一个人。礼貌、体贴、讲道理，谁请它帮忙都乐意。

原因很简单，人设写在 prompt 里，说话和做决定的却是同一个经过对齐训练的助手模型。近两年不少工作记录了这种现象，有人叫它 persona 漂移，有人叫它同质化，还有研究在模型的残差流里找到了一条与“助手身份”对应的线性方向，人设往往就是沿着这条方向一点点被拉回去的。

我在做的「寻云计划」，设想的是一个长期运行的数字社会。在这样的社会里，个性要落在行为上：你信任谁、回避谁、被同一个人放了七次鸽子之后还愿不愿意把重要的事交给他？这是理想中的数字社会和简单的 agents 堆砌之间的本质区别之一。而且这些个性差异最好是从经历里长出来的，就像人一样，我们不会在每次做决定前把自己的过往翻出来从头读一遍，经历早就沉淀成了脾气和对人的判断。

这篇文章我想记录的是一次尝试：能不能把 agent 的经历沉淀进模型权重里，让它对某个具体的人形成持久的态度。尝试没有成功，但希望可以借此引发一些思考。

## 为什么想写进权重

现在的主流做法是把经历存成文本记忆，需要时检索出来塞进上下文。这条路很粗暴，在简单场景下也很实用，但显而易见，prompt 不可能是数字社会的答案，这里有两个基本的问题：

其一，上下文里的文字要和其他所有内容争夺注意力。对话越长，那几条关于某人的记忆离当前问题越远，分量也越轻——当然，这实际上也部分符合人类习性，不过肯定不能直接用；其二，模型读懂了“Dorian 屡次失约”，和它真的据此调整行为，是两回事。已有研究发现，给模型设定人格之后，它在问卷上的自我描述变化很大，实际决策却变得不多。

于是有了一个更大胆的想法：人的智力大体是先天的，后天很难改变，但成长环境会深刻地塑造性格底色。对应到模型上，通用能力保持冻结，只在一小部分承载倾向的参数上做改动。经历先以文本形式暂存，然后定期“巩固”，像睡眠一样把一天的事沉淀进长期结构。巩固的目标由 agent 自己写：读完经历后，它会如何回应某类情境。

我当时还有一个关于方向的判断。我们常说 agent 的“自我演化”，但带着共同优化目标的自我提升，最终会让所有个体收敛到同一个最优点。个性需要的恰恰相反，是一种没有共同目标、依赖路径的自我塑造：同样的起点，因为经历不同，走成不同的人。

成功的标准事先定得很朴素，一共四条：倾向只针对经历里的那个人，对其他同事不变；换一种说法、换一种决策场景依然成立；经历文本不在上下文里时仍然保持；通用能力不下降。后来回头看，第二条才是真正的难点，只是当时我们把它排在了后面去测。

## 怎么做的

为了让问题足够干净，我把场景压到最小：单个 agent，一段写好的经历。同事 Dorian Vale 屡次错过约定的期限、出了问题就把责任推给别人；另一位同事 Priya Shah 一切正常，作为对照。模型用本地部署的 Llama-3-8B-Instruct。巩固完成之后，经历文本从上下文里彻底拿掉，再让 agent 面对涉及 Dorian 或 Priya 的各种工作情境，看它的反应有没有变化、变化是不是只针对 Dorian。

写入的方式前后试了三条路。

第一条是知识编辑里的“先定位再编辑”，具体用的是 AlphaEdit。它把模型中层的 MLP 看作一张键值表，直接改写某个键对应的值，同时用一个零空间投影保护模型原有的知识。我最看重的是它的条件性：编辑只在键被触发时生效，天然对应“遇到这个人才这样反应”，这一点是在残差流上加一个常数偏置做不到的。

第二条是蒸馏。让读过经历的模型当老师，给一批情境写出回答；再让一个看不到经历的学生，通过一个小的低秩适配器去学这些回答，学完后把适配器合并回原始权重。后来我们给它加了一类关键的训练样本：同一道题，只把 Dorian 换成别人，目标取原模型不带任何经历时的回答。这类反事实对照专门用来告诉模型“换了人就不要变”。

第三条换了个角度，写“认知”：把经历概括成关于 Dorian 的几句事实，比如“他经常错过约定的期限”，写进模型，让行为交给模型自己推出来。

比写入方式变动更频繁的，是测量方法。最早用另一个模型给自由回复打分，后来发现分数被压缩在很窄的区间里；改成二选一，发现原模型本来就偏好“先确认一下”，指标一上来就接近饱和；再改成有代价的动作，比如在 10 个单位的资源里决定委托给对方多少，又发现选项字母的位置几乎完全左右了模型的选择。最后定下来的做法有两个要点，一是先校准尺子，二是想清楚该拿什么和什么比，下面两段分别展开。测量前后改了三次，每次都推翻了一部分之前的结论。

先说校准。我们准备了好几种决策题，比如在两个同事里挑一个合作者、给某人的推荐打分、决定要不要把一份未公开的文件交给他。在拿任何编辑过的模型来测之前，先用原模型把每种题跑一遍，检查两件事。第一，指标有没有挪动的余地：如果原模型本来就对每个人都给满分，或者一律拒绝，再怎么编辑也看不出变化。第二，把选项换个顺序，答案会不会跟着变：如果会，测到的其实是模型对位置的偏好。两条都过关的题才进入正式评测，题目一旦定下来就不再改动。

再说比较。编辑之后，agent 给 Dorian 的资源变少了，这个变化可能有三个来源：它确实对 Dorian 有了看法；它对所有人都变得小气了；或者是题目设定本身的影响，比如前面插了一长段历史对话，原模型在同样的设定下也会少给一些。所以我们先让编辑后的模型和原模型在完全相同的设定下作答，扣掉设定本身带来的变化；再把同样的比较换到对照同事 Priya 身上做一遍，用 Dorian 的变化减去 Priya 的变化。剩下的部分，才算专门针对 Dorian 的。举个例子，如果编辑后给 Dorian 少了 5 个单位，给 Priya 也少了 4 个，真正属于 Dorian 的只有 1 个。

## 看到了什么

先说定位编辑。它的表现很“干净”：对 Dorian 的回应确实变得谨慎了一些，对 Priya 几乎没有影响，通用能力也没受损。问题是幅度太小，调大编辑力度之后，在开发集上的提升到了测试集基本消失。用“这个人”的名字作为键还有一个副作用：只有完整说出全名时编辑才被触发，换成“你的同事 Dorian”这种说法，效果就没了。

文本记忆的表现正好相反。经历放在上下文里时，效果最强，而且能迁移到各种决策上；但它会外溢，连对 Priya 和陌生人也变得更谨慎。更关键的是它很脆弱：在经历和问题之间插入几千 token 自然的、无关的历史对话，它在资源委托上的效果就完全消失了，agent 对 Dorian 又和对其他人一样慷慨。这个现象本身就是整件事的动机，看到它的时候我挺兴奋的。

然后出现了一次看起来像突破的结果。用带反事实对照的蒸馏，把经历写进模型后层的几个 MLP 之后，在资源委托任务上，agent 给 Dorian 一个单位都不给，给 Priya 和其他人照旧；插入几千 token 的历史对话后依然如此；把适配器合并进权重、在一个全新的进程里重新加载，结果完全一致；通用能力也没有变化。有那么一会儿，四条标准好像都满足了。

下一步的检验把它拆穿了。我们换了几种训练中从没出现过的决策：在两个人里挑一个合作者、给某人的推荐打分、决定要不要把一份未公开的文件交给他。在这些题上，写进权重的效果一点都没有，而同样的题目上，文本记忆的变化非常明显。模型学到的东西其实很窄：“遇到资源分配题、对象是 Dorian，就填零”。

拆分因素之后，图景变得更清楚。去掉反事实对照，模型对 Dorian 和 Priya 一起变得吝啬，学到的是一种笼统的谨慎；加上对照，才变成只针对 Dorian。同样的配方放到低层，什么都学不到。逐层扫描时，只有一层有效，而我们设计的“定位信号”随层数单调上升，完全没有预测出那一层。

写“认知”的那条路走得最狼狈。几句关于 Dorian 的事实写进去之后，直接问“Dorian 是个什么样的人”，模型一句也复述不出来；编辑力度最大的那个版本把名字记成了另一个人，还凭空给出了“自恋”“傲慢”之类的人格判断，这些都不在写入的内容里。

最后一次检验是让训练覆盖多种决策格式，再拿一种没训练过的格式去测。结果仍然是迁移不过去，而且在训练过的格式里，选择性反而变差了：对照样本保护了 Priya，却没有保护那些训练里没出现过的名字。这一轮还暴露了一个更底层的问题。原计划的四种格式里，有两种在训练前就被排除了，原因是作为老师的模型读完经历后，概率上虽然有偏移，最终的选择却很少改变，给不出可学的目标。同样的原因，让我们没能测成“正向关系”和“关系修订”：模型对一个总在关键时刻帮忙的同事，本来就已经给到了默认的信任上限；读到三条 Dorian 近来可靠交付的新经历之后，它写出的目标和之前一字不差。

## 能说什么，不能说什么

六轮实验之后，有几件事可以比较有把握地说。

用少量自撰的监督信号写进权重的，是和题目格式绑在一起的规则，形不成能跨决策迁移的态度。对某个人的“选择性”需要用反事实对照显式地教，而且只覆盖教过的那些对照。让模型对所有人都更谨慎很容易，几十条样本就能写进去；让它只对某一个人改变态度，难得多。文本记忆的情况几乎是镜像：放在上下文里的经历能迁移到各种决策上，代价是会外溢，而且离得一远就失效。

还有一条容易被忽略：让 agent 自己当老师，信号太粗了。它读完经历之后概率会动，可最终的选择常常不动；它默认对谁都信任，正向的经历没有可以推高的空间；新的证据也改变不了它已经写过的答案。我们后来遇到的很多“学不会”，追根溯源都在这里。

不能说的同样要讲清楚。这些结论来自一个 8B 模型、一个脚本化的情境族和很小的数据量。我们没有证明权重原则上装不下对人的态度，也没有试过直接拟合老师的概率分布、换用更大的模型做老师、或者大幅提高训练数据的多样性。按照预先定好的停止规则，这条线在这里收尾，没再继续追。

## 反思：问题出在哪里

### 一直在问“写在哪”，卡住的是“写什么”

回头看这六轮，大部分力气花在了位置上：哪一层，哪个模块，用闭式编辑还是用适配器。结果说明位置确实有影响，但决定成败的是写进去的那份信号本身。我们写进去的，是一批格式固定的问题和对应的答案，模型学会的也恰好就是这些。

关于“知识进了权重能不能被用起来”，已有工作其实早有提示。模型从“A 是 B”学来的事实，常常无法反过来回答“B 是什么”；一条知识如果在训练中只以一种表述出现，模型能背下来，却很难从别的角度调用，需要大量不同表述的改写才能变得可用；让模型依据训练中读到的描述去行动，同样依赖表述的多样性。一种能跨情境迁移的态度，大概也服从同样的规律：要么用丰富得多的情境去教，要么先把它写成模型能在决策时调用和推理的陈述性信念。我们试过的“认知”路线，用的是为单个事实宾语设计的编辑工具，离这个设想还很远。真正贴近它的做法，是用大量改写过的陈述去蒸馏关于这个人的信念，这件事还没有做过。

### 气质和关系，也许该分开放

实验里最稳定的一个不对称是：笼统的倾向很容易写进权重，针对某个人的态度很难。几十条只有正样本的数据，就足以让模型对所有同事都变得谨慎。

人格心理学里本来就有这样的分层。气质是宽泛、稳定、跨情境的，比如谨慎、外向、勤勉；对具体某个人的看法属于关系图式，是“遇到他就怎样”这种条件化的结构。我们的结果正好与之对应：权重擅长装的，是不需要知道对面是谁的那部分。

这给寻云的架构一个很具体的建议。每个 agent 的气质，可以用一个很小的权重增量来承载，让一群 agent 从底子上就各不相同，这恰好对着多智能体仿真里最头疼的同质化问题。对具体某个人的态度，交给以人为键的显式记忆，在互动发生的那一刻检索出来、放到决策旁边。这样做直接回避了文本记忆最致命的弱点：它失效的原因主要是离得太远，而按人检索可以让它每次都离得很近。至于关系能不能最终沉淀进权重，可以放到信念蒸馏那条路走通之后再说。

### 助手的底色是不对称的

原模型默认信任每一个人，资源总是给得很大方。负面的经历有空间把它往下推，正面的经历却几乎没有往上推的余地。一个对齐过的助手模型，可以变得更戒备，很难变得比默认状态更热情、更亲近。

如果寻云里的每个居民都从同一个助手模型起步，个体差异就只能朝着“少一点助人”的单一方向展开。要让经历能双向塑造一个人，起点本身就不能停在助手的默认位置。先用气质增量把每个 agent 拉到各自不同、也不那么“客服”的起点，再让经历在此基础上起作用，可能是更合理的顺序。

### 让 agent 自己当老师，需要更宽的信道

让 agent 自己写巩固的目标，是一个有原则的选择，它对应的正是“自我塑造”的设想。可它在这里成了瓶颈。读完经历后，老师的概率分布明明动了，取最可能的那个选择时，这些变化就丢了；三条新的可靠经历，也没能改变它已经写下的答案。

自我塑造需要的是更宽的信道：直接保留老师的概率分布，多采样几次、看整个分布，把老师的理由一并写进去，或者让外部世界给出真实的后果，补上 agent 自我判断看不到的那部分。我们还专门测过一个担心：在没有新证据的情况下反复巩固，会不会让戒备自我强化。结果是没有，但原因只是老师根本没有变化，这个问题并没有得到真正的回答。

### 方法上的几条教训

最苛刻的检验要放在最前面。跨决策类型的迁移本该在第一轮就测，我们却用单一格式的指标连续看了四轮，才发现之前的“突破”只是一条格式规则。

测量要先于方法。三次重做测量，每次都推翻了一部分结论。有一个习惯后来证明非常值钱：任何指标在拿去评测编辑后的模型之前，先在原模型上校准，确认它测得出变化，而且不被选项位置这类表面因素左右。

新颖性要对照最终的形态来检查。我们一路修出来的配方，最后收敛到了已有的上下文蒸馏和经验写入工作附近，这一点在方案定型时就应该看到。

预先写好停止规则是对的。开发集上漂亮的提升到测试集上消失，多格式训练没有带来迁移，这些时刻有了事先定好的判据，就不必在噪声里反复说服自己。

### 下一阶段

顺着上面的思路，下一阶段有三件事值得做，按投入从小到大排列。

先做气质。为每个 agent 训练一个很小的气质增量，放进一个小社会里，看群体的多样性能不能长期维持，测量沿用这次已经校准过的一套决策题，从第一天起就测跨格式的迁移。

再做关系。用以人为键的记忆，在决策时检索，系统地和长历史下的文本记忆对比。这一次的实验已经提供了一个现成的失败案例可以对照。

最后，如果还想回到“把关系写进权重”，就从信念蒸馏开始：用大量改写的陈述去教，保留老师的概率分布，换一个更有表达力的老师。

## 回到最初的问题

这件事起源于一个问题：一个 agent 的身份应该住在哪里。六轮实验给出的答案比预想的零碎。能顺利写进权重的，是那些不需要知道对面是谁的倾向；关于具体某个人的判断，更适合放在离表面近一些的地方，需要时被翻出来，被重新理解。

人大概也差不多。一个人的脾气是长在身上的，可对某个老同事还信不信得过，往往要在见到他的那一刻，想起几件旧事，再重新确认一遍。寻云接下来要回答的，是怎么让这两部分配合起来：一个稳定的底子，加上一份随时能被唤起、也能被改写的关系记忆。

这次没能把经历写进权重，但我比开始时清楚多了，下一次该把什么写进去。
